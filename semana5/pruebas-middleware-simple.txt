Prueba 4: Token incorrecto

Explica qué debería pasar si el token no coincide con el esperado.

Respuesta: El sistema debe negar el acceso y responder que el token de demostración no es válido.

5. ¿Qué hace el middleware simple?

Respuesta: El middleware verifica si la solicitud incluye un token válido antes de permitir el acceso a la ruta protegida.

6. ¿Por qué este middleware no debe confundirse con seguridad real?

Respuesta: Porque utiliza un token fijo y simple solo para fines pedagógicos. No implementa mecanismos reales de autenticación o cifrado.

7. ¿Qué aprendiste sobre rutas públicas y rutas protegidas?

Respuesta: Aprendí que las rutas públicas pueden consultarse libremente, mientras que las rutas protegidas requieren validación previa mediante un middleware.
